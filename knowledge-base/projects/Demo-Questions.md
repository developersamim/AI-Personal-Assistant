# Demo Questions and Expected Answers

These examples are useful for testing retrieval.

- **Question:** Where does Alex live?
  **Answer:** Alex lives in a small apartment above a bakery in Portland.

- **Question:** What is Alex building?
  **Answer:** Alex is building a local-first personal assistant using RAG, Chroma, HuggingFace embeddings, and Ollama.

- **Question:** Why does the project use RAG?
  **Answer:** RAG lets the assistant retrieve relevant facts at question time instead of relying only on model memory.

- **Question:** What should the assistant do when it lacks information?
  **Answer:** It should say that it does not know rather than inventing details.

- **Question:** Is Alex real?
  **Answer:** No. Alex Morgan is fictional demo data created for this project.
